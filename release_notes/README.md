# Release Notes

This folder contains all release notes and release-related documentation for the Design System Project.

## 📁 Contents

### Release Notes
- `RELEASE_NOTES_v*.md` - Individual release notes for each version
- `RELEASE_NOTES_TEMPLATE.md` - Template for creating new release notes

### Release Process
- `RELEASE_CHECKLIST.md` - Checklist for the release process

## 📋 How to Use

### Creating a New Release
1. Copy `RELEASE_NOTES_TEMPLATE.md` to create a new release note file
2. Follow the template structure and update version numbers
3. Use the checklist in `RELEASE_CHECKLIST.md` to ensure all steps are completed

### Version History
The release notes are organized chronologically by version number:
- v1.0.0 - Initial release
- v1.2.x - Minor updates and improvements
- v1.3.x - New components and features
- v1.4.x - Latest releases with enhancements

## 🔗 Related Files

- `../CHANGELOG.md` - Detailed changelog with all changes
- `../README.md` - Main project documentation
- `../CATALOG_README.md` - Component catalog and examples

## 📝 Notes

- All release notes follow a consistent format defined in the template
- Each release note includes links to relevant documentation
- Breaking changes are clearly marked with warnings
- Dependencies and compatibility information is included
